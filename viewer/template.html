The first line is the question, wrapped in **double asterisks:**. The lines after it are the answer. Lines like ![](fi/name.png) show an image.

Settings

Editing saves your changes to the GitHub repo through the GitHub API. To allow that, create a fine-grained personal access token at GitHub → Settings → Developer settings → Fine-grained tokens. Limit it to this repository and give it Contents: Read and write. The token is stored only in this browser.
